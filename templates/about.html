Project Architecture & Documentation

Comprehensive technical details for college project viva, evaluation, and documentation.

1. Problem Statement

Crop yield unpredictability directly affects farmers' income, food security, and supply chain logistics. Traditional agricultural advice relies on coarse regional averages that do not consider farm-specific soil test reports (pH, N, P, K) or localized microclimatic parameters (temperature, humidity, precipitation, soil moisture).

Agri Yield Predictor applies supervised machine learning regression to model non-linear physiological interactions between soil chemistry, moisture, temperature, and crop biological potential.

2. System Architecture & Tech Stack

  • Backend Framework: Python Flask (REST APIs, Jinja2 rendering, request validation)
  • Machine Learning: Scikit-learn (Linear Regression, Random Forest, Gradient Boosting)
  • Database: SQLite (persistent local storage for prediction logs in database/predictions.db)
  • Frontend UI: Responsive, accessible, farmer-friendly interface with Tailwind CSS / bespoke clean styling
  • Data Preprocessing: One-hot categorical encoding, outlier filtering, feature normalization

3. Machine Learning Evaluation Metrics

The models are evaluated using three primary regression metrics on the 20% unseen test split:

R² Score (Coefficient of Determination)

R² = 1 - (SS_res / SS_tot)

Measures the proportion of yield variance explained by the features (Target: > 0.90 for ensemble models).

MAE (Mean Absolute Error)

MAE = (1/n) * Σ |y_actual - y_pred|

Provides the average absolute error magnitude directly in tons per hectare.

RMSE (Root Mean Squared Error)

RMSE = sqrt((1/n) * Σ (y_actual - y_pred)²)

Penalizes larger outliers more heavily, indicating prediction stability.

5. Academic Project Viva Q&A

Q: Why did you choose Gradient Boosting over simple Linear Regression?

A: Agricultural yield exhibits non-linear response curves (e.g., Liebig's Law of the Minimum and excessive rainfall causing waterlogging or nutrient leaching). Linear regression cannot capture quadratic or threshold response functions without manual feature engineering, whereas tree-based ensembles (Random Forest, Gradient Boosting) naturally partition feature space and model complex interactions.

Q: How is total production derived?

A: Total production is calculated as: Total Production (tons) = Predicted Yield (tons/ha) × Land Area (ha).

Q: How does the system handle database storage?

A: Each prediction query is recorded with a timestamp, crop, area, input parameters, prediction score, and model name into an SQLite database file (database/predictions.db), ensuring auditability and history inspection.
